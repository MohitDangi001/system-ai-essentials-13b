
# AI Learning Log — v0.3

## Project
Creative Geometric Sea Turtle

## 1. What did I want the program to do?

I wanted to create a colourful geometric sea turtle inspired by a low-poly reference image, using Turtle and Pillow together.

## 2. Prompt used

"Help me create a colourful geometric sea turtle using Python Turtle and Pillow. I want a black background, a colourful polygonal shell, a head, four flippers and a tail. Explain the code step by step and help me combine both libraries."

## 3. How many iterations did it take?

Several iterations were needed to build and refine the artwork.

The process included:
- Creating the background using Pillow.
- Drawing the first geometric shell.
- Adding the head and eye.
- Adding four flippers and a tail.
- Reorganising the program into one complete file.
- Refining the shell and overall composition.

## 4. What changed in my instructions?

Initially, I asked for a colourful turtle. After sharing my reference image, I clarified that I wanted a geometric sea turtle closely inspired by that image.

I later requested the complete program in one code block so I could replace the entire file at once.

## 5. What did AI get wrong or what needed improvement?

Some early shapes looked too angular, disconnected or different from the reference. I checked the output by running the program and sharing screenshots. We adjusted the drawing based on the visual results.

## 6. Did the final output match my prediction?

The program successfully generated a colourful geometric sea turtle on a black background. It achieved the main objective, although it is not an exact reproduction of the reference.

## 7. What did I learn?

- How Turtle draws geometric shapes.
- How Pillow creates and saves images.
- How one library can provide an image used by another library.
- How functions and loops reduce repeated code.
- How to debug and improve a program through testing.

## Something AI got wrong
The first turtle design did not fully match the visual reference, especially the shape and arrangement of the turtle parts.

## How I discovered and corrected it
I compared the program output with the reference image, identified the differences, and refined the drawing.
